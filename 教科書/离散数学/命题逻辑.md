# 命题
自然语言中**能够判断真假**的**陈述句**。
若表述意义为真，则称为真命题, vice versa。
注：是否为命题，与其是否具有唯一真值有关，而与是否可知无关。

# 类型
+ 原子命题：一个简单的谓句。
+ 复合命题：命题复合组成。

# 符号化
通常使用英文字母表示命题，如$x,X,y,Y,z,Z,a,A,p,P,q,Q,etc.$ 
+ 命题常量：已有特定含义的符号。
+ 命题变元：没有赋予具体内容的符号。

# 连接词
+ 就是上面命题的连接。和[[逻辑运算]]很像。
+ $\cap \rightarrow \land$ 析取
+ $\cup \rightarrow \lor$ 合取
+ $\sim \rightarrow \lnot$ 否定
+ $\rightarrow$ 蕴含，$A \rightarrow B = A \land \lnot B$
+ $=\  \rightarrow \iff$ 等价
+ $\models$ 命题蕴含
可以去查看它们的[[真值表]]
# 否定式
即某命题$p$，有$\lnot p$。值理所当然地与原命题相反。

# 公式
是[[逻辑运算]]的换皮。不过那个不用记名字，这个要，就很烦人。
+ **吸收律**：$A \lor (A \land B) \iff A$ , vice versa.
+ 排中律：$A \lor \lnot A \iff 1$
+ 矛盾律：$A \land \lnot A \iff 0$
+ 双重否定律：$\lnot \lnot A \iff A$
+ **蕴含等值式**：$A \rightarrow B \iff \lnot A \lor B$
+ 等价移植式：$A \leftrightarrow B \iff (A \rightarrow B) \land (B \rightarrow A)$
+ 假言移位：$A \rightarrow B \iff \lnot B \rightarrow \lnot A$
+ 等价否定等值式：$A \leftrightarrow B \iff \lnot A \leftrightarrow \lnot B$
+ **归谬论**：$(A \rightarrow B) \land (A \rightarrow \lnot B) \iff \lnot A$

# 值
+ 重言式：恒为**真**。
+ 矛盾式：恒为**假**。
+ 可满足式：else above.

# 范式
### 主析取范式
由若干**极小项**的**析取**构成的公式。
$p \rightarrow q$
可划为：
$(\neg p \land \neg q) \lor (\neg p \land q) \lor (p \land q)$

### 主合取范式
由若干**极大项**的**合取**构成的公式。
$(p \land q) \lor r$
可划为：
$(p \lor q \lor r) \land (p \lor \neg q \lor r) \land (\neg p \lor q \lor r)$


有上可一窥极大项于极小项的定义。
### 极大/小项
##### 极大项
- 由**所有变元**的**合取**构成
- 每个变元以**原变量**或**否定**形式出现恰好一次
- **只有一组赋值**使其为真
- 真值表中有且仅有一行为 1
- n 个变元 ⇒ 共有 $2^n$ 个极小项
##### 极小项
- 由**所有变元**的**析取**构成
- 每个变元以**原变量**或**否定**形式出现恰好一次
- **只有一组赋值**使其为假
- 真值表中有且仅有一行为 0
-  n 个变元 ⇒ 共有 $2^n$ 个极大项
##### 编号
编号$M_n$，其中的n转换为二进制数，就代表着其中表达式的值，1表示否定。
如$p,q,r$，极大项$M_6$ =$(\neg p\lor \neg q \lor r)$
