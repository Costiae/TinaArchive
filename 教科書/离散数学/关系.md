# 笛卡儿积
对于$A$, $B$, $A$中的所有元素作为第一元素，$B$中所有元素作为第二元素，组成序偶，所有序偶组成的集合为**A和B的笛卡儿积** 。表示为：$A \times B = \{<x,y>|x \in A, y \in B \}$ 

# 定义域
对于集合`R : <a, b>`，a的范围称**R的定义域**或**前域**，记为**dom R** (Domain)；b的范围称**R的值域**或**ran R** (Range)；dom R 和 ran R 合称**R的域**，记为**fld R** (field)。
形式化表示：
+ $dom\ R=\{x\ |\ \exists y, <x, y> \in R \}$
+ $ran \ R=\{x\ |\ \exists y, <y, x> \in R\}$ 
+ $fld\ R=dom\ R \cup ran\ R$

# 特殊的关系
+ 空关系：$\emptyset$
+ 全域关系：$E_A=\{<x,y>\ |\ x \in A,y \in A\}$
+ 恒等关系：$I_A=\{<x,x>\ |\ x \in A\}$

# 运算
+ [[逻辑运算]]
+ 复合运算：$\circ$ ：$F \circ G = G(F(x))$ 
+ 逆运算：$F^{-1}$
+ 幂运算：$R^n=R^{n-1} \circ R$
  定理：
  1. $R^m \circ R^n=R^{m+n}$
  2. $(R^m)^n=R^{mn}$
#### 闭包运算：
定义：关系$R,R'$，$R,R' \in A, I^A \subseteq R' \ \land R \subseteq R' \ \land \forall R'' \supseteq I_A,R' \subseteq R''$ 
简单地说，向一个集合或关系中添加尽可能少的元素，使其满足某种指定的性质（如自反性、对称性、传递性）。
三种闭包：
1. 自反闭包：`r(R)`，添加`<a,a>`使其拥有自反性。
2. 对称闭包：`s(R)`，对`<a,b>`，若`<b,a>`不存在，则添加之。
3. 传递闭包：`t(R)`，反复添加通过中间元素间接相连的序对，直到稳定。

#### 封闭性
经过某种运算之后，原有性质**没有**发生变化，则称该关系性质在该运算下具有**封闭性**，或称该性质对这一运算是**封闭的**。

# 等价/偏序关系
### 等价关系
**自反** + **对称** + **传递**。
##### 商集
给定集合A，等价关系R，即找等价关系R里的小团体。
>**例子**：  
>设 A={1,2,3,4,5}A={1,2,3,4,5}，定义等价关系“模 2 同余”（即奇偶相同）。
>- 等价类：奇数组 {1,3,5}{1,3,5}，偶数组 {2,4}{2,4}。
>- 商集 A/R={{1,3,5},{2,4}}。


### 偏序关系
**自反** + **反对称** + **传递**。
##### 哈斯图
和上面一样，是偏序的特殊机制。
规则：
- 省略自环：每个元素自反（a≤aa≤a），但不画自环。
- 省略传递边：若 a≤ba≤b 且 b≤cb≤c，则 a≤ca≤c 的边不直接画，只画 a→ba→b 和 b→cb→c。
- 方向由高度表示：如果 a≤ba≤b，则 aa 画在 bb 的下方（或不同层级），用连线连接。
###### 特殊点
- **极大元**：最顶端**没有线向上**的点
- **最大元**：顶端**唯一**且**所有点都能到达**它
- **上界**：在子集上方的某个点（可能有多个）
- **上确界**：上界中最低的那个点（可能刚好是子集的最大元，也可能在其上方）
**vice versa.**
