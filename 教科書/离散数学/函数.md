又名**映射**，**变换**，**对应**，是一种特殊的二元[[关系]]。

# 定义
$\forall x \in A, \exists!y \in B,<x,y> \in f$ 则称关系$f$为集合$A$到$B$的**函数**。记为$f:A \rightarrow B$ 或$y=f(x)$。
> 说人话就是关系+x有唯一对应的y，就是函数。

|     | x             | y          |
| --- | ------------- | ---------- |
| 称   | 自变量(argument) | 函数值(value) |
| 域   | 定义域(domain)   | 值域(range)  |

# 特点
+ 定义域是集合A，而不能是A的任意一个真子集。
+ $\forall A \in dom, \exists! y \in ran$ 
+ 集合A->B的函数$f$的值域$f(x)$是集合B的子集，$f(A) \subseteq B$
+ 集合A->B的函数$f$的基数等于其定义域的基数，$|f|=|A|$
+ $f(x)$表示一个函数值，$f$是一个序偶的集合，因此$f(x) \neq f$ 
+ $B^A$表示A到B的全体函数的集合，即 $B^A=\{ f|f:A \rightarrow B \}$ 
+ 对于有限集合A,B，若$|A|=m,|B|=n$，那么，集合A到B可以定义出$n^m$种不同函数，即$|B^A|=|B|^{|A|}$ 

# 特殊函数
+ 单射：一对一映射$x \neq y \implies f(x) \neq f(y)$ 
+ 满射：B中每一个元素是A中一个或多个元素的函数值，即$f(A)=B$ 
+ 双射：单射+满射
