Set, 聚集到一起的对象构成的整体。 
# 表示法
1. 枚举： 如 `{1, 2, 3}`
2. 描述： 如 `{x | x > 1}`
3. 图形： 主要是Venn图。

# 关系
+ 基数：集合中的元素个数。`|A|`或`card(A)`表示。
+ `=` ：元素完全相等。
+ `∈` ：属于。`[element] ∈ [set]`。
+ `⊆` ：包含。`[set] ⊆ [set]`
+ `⊋` ：真包含。定义：`B⊆A & B≠A`。前者为后者的子集。
+ `~` ：补集。
# 计算
把这些计算当作[[逻辑运算]]（孙子像爷爷说是）。后续还会出现。全部转！
+ $\cup$ ：OR
+ $\cap$ ：AND
+ $\sim$ ：NOT
# 性质
1. 元素是确定的。
2. 元素是彼此不同的。（互异）
3. 元素是无序的。

# 常见的集合Preset
+ `N` Natural 自然数
+ `Z`, `I` Zahlen, Integer 整数
+ `Q` Quotient 整数
+ `R` Real 实数
+ `∅` 空集
+ `U` Universal 全集

# 幂集✏️
对于集合所有不同子集为元素组成的集合。记作$P(A)$和 $2^A$ 。
有点抽象，举例。
>设$A=\{\{\emptyset\}，0，1\}$ ，$P(A)$?
>解：$P(A) = \big\{ \varnothing,\ \{\{\emptyset\}\},\ \{0\},\ \{1\},\ \{\{\emptyset\}, 0\},\ \{\{\emptyset\}, 1\},\ \{0, 1\},\ \{\{\emptyset\}, 0, 1\} \big\}$ 

性质：若$|A|=n$, 则$|P(A)|=2^n$ 。
