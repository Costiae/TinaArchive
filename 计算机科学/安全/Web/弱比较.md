# 严格比较
记作`===`，其会先比较类型是否一致，若不一致，直接返回`false`，也就没后面什么事了。
而弱比较记为`==`。
# [[PHP]]的弱比较
总的有以下原则：
1. **布尔值优先**：如果比较中有 `boolean`，则另一边也会被转为 `boolean` 再比（`true` 转 1，`false` 转 0）。
2. **数字与字符串**：如果一边是 `int/float`，另一边是 `string`，则**字符串会被转为数字**再比较（直到遇到非数字字符）。
3. **比较数字字符串**：如果两边都是纯数字字符串（如 `"123"`），它们会被转为数字比较。
4. **比较数组**：数组与数组比较，比较键值对的数量和值（弱比较）；数组与非数组比较，数组总是更大。
5. **特殊值 `null`**：`null` 转为数字是 `0`，转为布尔是 `false`。

优先度自上而下。

### 字符串
在与**数字**比较中，其遵循以下规则。
- 对于开头有数字的，转换为开头的数字。如`"721Ciallo" -> 721`
- 对于开头没有数字的，转换为0。如`"Ciallo721" -> 0`
- 这一规则同样对科学计数法使用。如`"1145e4" -> 11450000`

在与**布尔**比较时，遵循以下规则。
- 若字符串为空，转换为false
- 若字符串不为空，转换为true
### 数字
在与**布尔**比较时，遵循以下规则。
- 若值为0，转换为false
- 否则为true
### 数组
空数组为false
